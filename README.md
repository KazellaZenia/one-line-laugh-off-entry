## The entry

Exactly one funny line:

**I bought noise-cancelling headphones to hear myself think; now all I hear is how loud I chew.**

The twist lands on the last clause: the headphones work too well, and the
only sound left is the wearer themself. Specific, concrete, surprising on a
cold read, and tight at 93 characters.

## How it works

`main.py` writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(UTF-8, 93 characters, one line). Pure Python standard library, no
third-party imports.
